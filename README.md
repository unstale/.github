# Unstale

We upgrade apps that are stuck on end-of-life versions of PHP, Laravel, Node.js, Python, Django and Rails.

You get one pull request that passes your existing tests and build, for a fixed price agreed before you pay, or your money back.

- [Get a free upgrade scan](https://unstale.dev/scan.html)
- [Pricing](https://unstale.dev/pricing.html)
- [Upgrade guides](https://unstale.dev/guides.html)

**Inviting us to your repository:** add **@unstale-bot** as a collaborator with write access. We never need production access or secrets, and you can remove the account once you've merged.
